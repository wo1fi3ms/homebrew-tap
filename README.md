# Homebrew tap

Homebrew formulae for [wo1fi3ms](https://github.com/wo1fi3ms) projects.

## Install

```bash
brew install wo1fi3ms/tap/macos-free
```

or

```bash
brew tap wo1fi3ms/tap
brew install macos-free
```

## Formulae

| Formula | Description |
|---|---|
| [`macos-free`](Formula/macos-free.rb) | The Linux `free` command for macOS ([source](https://github.com/wo1fi3ms/macos-free)). Installs the `free` command and its man page. |

Formulae build from the tagged source archive on your Mac; no prebuilt binaries are downloaded.
